# Animated website design preview

Open index.html directly in a current browser. No installation, server or internet is required. The preview dock provides section navigation, Motion on/off and a locally validated contact-form demo. All content is displayed from the supplied design artwork. The main page text is preserved inside high-resolution image sections; it is not a fully editable production HTML reconstruction. The navigation, menus, detail viewers, forms and animations use native HTML/CSS/JavaScript.

Use ?embed=1 to hide the review dock when embedding this project in your portfolio. project.js sends the non-sensitive slug and rendered height to the parent iframe using the onside-preview:resize message.

styles.css and project.js control the visual motion. index.json documents the source crop, section boundaries, control positions and artwork assets. index-content.json contains text extracted from the PDF, or header OCR for flattened exports; OCR copy may need proofreading. Source artwork cannot be edited as ordinary HTML text. Original Figma/source assets and fonts are needed for a fully editable rebuild.

Shopping, registration, playback, live account services and actual submissions are not connected. Forms never transmit or store data. Other destination pages not supplied in the source design are not implemented.
